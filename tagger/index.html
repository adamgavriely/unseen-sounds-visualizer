    How to tag

    Your job

    Each clip is 15–20 seconds. Watch it with sound. Use headphones, in a quiet room. Write down every sound that a hearing person would notice, except speech and music. For each sound, give: a name, when it starts and ends, whether you can see it, whether it is obvious from the picture, and how important it is.

    Do not use any AI tool, app or website. Tag by ear. You can replay a clip as many times as you want.

    What counts as a sound

    • Yes: vehicles, horns, sirens, alarms, animals, birds, footsteps, doors, knocks, machines, tools, kitchen sounds, water, rain, wind, thunder, bells, phones, crowd noise, bangs and crashes.
    • Yes: human sounds that are not words: laughing, crying, coughing, screaming, shouting, clapping.
    • No: speech (people talking), singing, music (on screen or as a soundtrack). Do not tag them.
    • If talking or music makes a sound hard to hear, tag it anyway if you can hear it.
    • Two different sounds at the same time = two rows.

    Name

    Type a word (for example dog) and pick a name from the list when one fits (for example Bark). If nothing fits, write your own short name (for example shopping trolley rattling).

    Start and end

    • Start is the most important time. Try to be within about half a second. Use Replay last 2 s to check it.
    • End can be rough.
    • Pause the video and press Set start = now or Set end = now. You can also type the number.
    • A sound that is there the whole clip: start 0, end = the end of the clip.
    • If a sound stops for more than about 2 seconds and then comes back, give it a new row.

    Visible?

    Answer for the time the sound plays.

    • Yes = you can see what makes the sound (the dog, the car, the door).
    • No = you cannot see it, or it is too small or too dark to recognise.
    • Visible only part of the time?
      • Short sound (under about 4 s): Yes only if the source is visible for most of the sound. If it appears only for a moment: No.
      • Long sound (about 4 s or more) where this changes: split it into two rows at the moment it changes. Example: a siren is heard from 2 s and the ambulance appears at 9 s → one row 2–9 visible No, one row 9–15 visible Yes.

    Obvious from the picture?

    Imagine this moment with the sound off. Would you still know this sound is happening?

    • Yes = the picture makes it clear. You see the dog barking with its mouth open; you see someone clapping.
    • No = you would not know. The source is off screen; or it is visible but not clearly making the sound (a phone lying on a table while it rings); or the sound does not match what you see.
    • If visible is No, obvious is almost always No.

    Importance (1, 2 or 3)

    How much would a person who cannot hear lose if nobody told them about this sound?

    • 3 = safety or story. Siren, alarm, gunshot, explosion, glass breaking, baby crying, doorbell or phone, scream, thunder.
    • 2 = useful information. Footsteps coming closer, a door closing, a dog barking, a car passing, applause.
    • 1 = background. Traffic noise, wind, rain, crowd murmur, air-conditioning hum.
    • Not sure between two numbers? Choose the lower one.

    Saving and sending

    • Your work saves automatically, but only in this browser on this computer. Use the same browser each time and keep this folder in the same place.
    • Press Export from time to time as a backup. It downloads one file (for example tagger_Name_2026-10-01_1830.json). Import loads such a file back.
    • When all clips are done, press Export and send the exported file.
    • Expect about 3–5 minutes per clip.
