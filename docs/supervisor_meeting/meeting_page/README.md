# Meeting page

- `index.html` — open this file in a browser (double-click). Works offline; videos and figures
  are in `demos/` and `figures/`. Notes and decisions are then saved in the browser only.
- Online version (notes saved to shared storage, readable from any device):
  https://claude.ai/artifact/Mdg3z3cbib7YUTAjVbxeSW
- `page.html` — the source published online (same content without the HTML wrapper).
  After editing it, run `python build_local.py` to regenerate `index.html`.

Keys: → / ← steps · Space play/pause · 1 2 3 choose clip · S submit the active decision ·
P presenter (hides private notes) · M numbers · Esc close.
