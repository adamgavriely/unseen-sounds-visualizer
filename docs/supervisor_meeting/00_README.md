# Supervisor meeting — what is in this folder and how to use it

*Prepared 17 September 2026. Everything here is a copy of files elsewhere in the repository
(the sources of truth are `docs/`, `docs/report/`, `LIMITATIONS.md`).*

## Files

| file | use |
|---|---|
| `01_supervisor_update.pdf` | **Send before the meeting.** Two pages: status, decisions needed, departures from the proposal, findings. |
| `02_executive_summary.pdf` | If he wants detail (14 pages, plain language). Point him to §1–3 and §9. |
| `03_thesis_draft.pdf` | The thesis (19 pages). Have it open at the results table (p. 9) and Figure 2 (last page). |
| `04_LIMITATIONS.md` | If he asks "what does this not show?" — the honest list. |
| `05_run_sheet.md` | **Your script for the 30 minutes**, minute by minute, with what to show when. |
| `06_questions_form.md` | The six questions with space to write his answers. Print or keep open. |
| `07_examples.md` | The worked examples with real numbers: what to say for each demo, and expected questions. |
| `08_how_to_run.md` | How to run the system on one video (if he asks "can I try it?"). |
| `meeting_page/` | **The guided meeting page.** Open `meeting_page/index.html` locally, or use the online link below. |
| `demos/` | Three test clips, `clean_*` (what a viewer sees) and `debug_*` (detections and gate verdicts printed under the panel). |
| `figures/` | The four report figures as PNG for quick showing. |
| `examples/` | Mid-clip frames of the three demos (if the videos will not play). |

## The three things to remember

1. The result is a **tie**, and the thesis says why (the sound detector). Say it first; do not let him discover it.
2. Everything tried is written down with a pass bar declared *before* it ran. "Failed" means the bar was not reached, not that it was sloppy.
3. You need **four decisions** (questions 1, 2, 3, 4 in the form); the other two can wait.
