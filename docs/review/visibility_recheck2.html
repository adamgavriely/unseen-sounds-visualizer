Visibility Re-check, round 2 (20 sounds)

For each sound:
  1. Press Play the sound. It plays from 0.5 s before the sound to 0.5 s after.
  2. Q1. Is the thing that makes THIS sound on screen while you hear it? Answer "yes" only if you see the actual source. If you see a look-alike (a bird is on screen, but the singing bird is a different one), answer "no".
  3. Q2. With the sound off, would a viewer already know this sound is happening? For example, lightning on screen means thunder is obvious; a man pulling the fire-alarm handle means the alarm is obvious.
  4. If you really can't tell, pick "unsure". Add a note if something is odd, like a wrong label.
